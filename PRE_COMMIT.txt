COME ABILITARE PRE-COMMIT
=========================

Prerequisiti
------------
- Docker Desktop installato e avviato, con Docker Compose disponibile.
- GNU Make installato e disponibile nel PATH.
- Git e Python installati; aprire il terminale nella root del repository.

Installazione e attivazione
---------------------------
Aprire un terminale nella cartella principale del progetto ed eseguire:

    python -m pip install pre-commit
    pre-commit install

Il secondo comando registra l'hook Git nel repository locale. Da quel momento,
prima di ogni commit, l'hook costruisce (o aggiorna) l'immagine Docker ed esegue
solo `chatbot_tests.test_smoke.DjangoSetupSmokeTest.test_django_apps_are_ready`
nel servizio `uniticket` definito in `uniticket/docker-compose.yml`. Il test è
in `uniticket/extensions/chatbot_tests`, montato dal Compose in `/extensions`
e incluso nel `PYTHONPATH`, così non si sovrappone ai test già presenti
nell'immagine uniTicket. Il container viene eliminato al termine.

Esecuzione manuale
------------------
Per eseguire manualmente i test nel container:

    make test-django-docker

Per eseguire manualmente l'hook su tutti i file:

    pre-commit run --all-files

Se l'hook viene rimosso o non è attivo, eseguire di nuovo `pre-commit install`
dalla root del repository. Docker Desktop deve restare avviato anche durante
il commit. La cartella `uniticket/extensions` viene montata nel container in
sola lettura, come configurato in Compose.
