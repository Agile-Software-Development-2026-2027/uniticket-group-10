ENABLING PRE-COMMIT
===================

Prerequisites
-------------
- Docker Desktop installed and running, with Docker Compose available.
- GNU Make installed and available on your PATH.
- Git and Python installed; open a terminal at the repository root.

Installation and setup
----------------------
Open a terminal in the project root and run:

    docker compose -f uniticket/docker-compose.yml build uniticket
    python -m pip install pre-commit
    pre-commit install

The first command builds the image. The third installs the Git hooks for this
local repository. On every commit, the pre-commit hook runs the tests in the
`chatbot_tests` package, even if the commit only changes the README. It starts
a temporary container using the existing image. The tests are in
`uniticket/extensions/chatbot_tests`; Compose mounts this directory at
`/extensions`, which is included in `PYTHONPATH`, so test changes are visible
without rebuilding the image. The container is removed when the tests finish.

The commit-msg hook also checks that the commit message follows the required
format. Rebuild the image with the `build` command if the Dockerfile or
dependencies installed in the image change.

Running the checks manually
---------------------------
To run the tests in the container:

    make test-local

To run the pre-commit hook on all files:

    pre-commit run --all-files

If a hook is removed or is not active, run `pre-commit install` again from the
repository root. Docker Desktop must remain running during commits. The
`uniticket/extensions` directory is mounted in the container as read-only, as
configured in Compose.
