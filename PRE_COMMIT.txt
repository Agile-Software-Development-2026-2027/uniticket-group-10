COME ABILITARE PRE-COMMIT
=========================

Prerequisiti
------------
- Python installato e disponibile dal terminale come `python`.
- Git installato e repository aperto nella cartella principale del progetto.
- GNU Make installato e disponibile dal terminale come `make`.

Su Windows, installare una distribuzione di GNU Make e verificare che il comando
`make` sia incluso nel `PATH`. L'hook esegue `make test-local`, quindi senza
GNU Make i commit vengono bloccati con un errore `Executable 'make' not found`.

Installazione e attivazione
---------------------------
Aprire un terminale nella cartella principale del progetto ed eseguire:

    python -m pip install -r test_requirements.txt
    pre-commit install

Il primo comando installa anche pre-commit e pytest. Il secondo registra
l'hook Git nel repository locale. Da quel momento, prima di ogni commit,
verranno eseguiti i test presenti in `tests/unit_integration/`.

Esecuzione manuale
------------------
Per eseguire l'hook manualmente su tutti i file:

    pre-commit run --all-files

Per lanciare direttamente i test Unit/Integration:

    python -m pytest tests/unit_integration/ -v

Se l'hook viene rimosso o non è attivo, eseguire di nuovo `pre-commit install`
dalla cartella principale del repository.
